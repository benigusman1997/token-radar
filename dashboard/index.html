Implied value is this radar's own claim from the snapshot's figures — not a prediction that a token will be issued, or what it will be worth if one is.

How the value is built

Each category's multiple is the median market cap / TVL of the live-token protocols in that category — the market's own price for the same kind of protocol. Fewer than three comps, and the category falls back to the global median. Then:

implied = TVL × multiple[category]
        × (1 + clamp(7d change, −60%, +120%) × 0.5)
        × (0.6 + min(age, 1095 days) / 1095 × 0.4)
        × (1 + 0.05 × min(chains − 1, 4))

No protocol name is ever special-cased: the same function scores every row. The table below is computed from this snapshot, not written by hand.
